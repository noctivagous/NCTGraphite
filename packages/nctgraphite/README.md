# `@nct/nctgraphite`

This package will contain the distributable NCTGraphite React library.

Planned contents:

- Layout primitives and controls
- Themes and design tokens
- XML parsing, validation, and rendering
- Bindings, scopes, stores, and logic components

Every public export keeps the full `NCTGraphite` prefix. A library component
is added only when real application work justifies it.
